Principais Implementações Desta Etapa:

Rolagem Suave (GSAP ScrollToPlugin): Navegação fluida entre as seções da página, com compensação automática da altura do cabeçalho (offsetY) para não esconder o conteúdo.

ScrollSpy (Intersection Observer): Detecção inteligente da seção atual na tela. O menu atualiza automaticamente a classe ativa, destacando a página atual com um contorno azul.

Glassmorphism Dinâmico: O fundo do cabeçalho inicia transparente e se torna translúcido (efeito de vidro com desfoque) quando o usuário começa a rolar a página.

Menu Responsivo: Adaptação completa para dispositivos móveis com um botão hambúrguer interativo que abre uma gaveta de navegação.
