Principais Implementações Desta Etapa:

Animação em Cascata (Stagger): A classe .hero-anim foi distribuída pelos elementos textuais. O GSAP agrupa esses itens e anima de baixo para cima com um atraso dinâmico entre eles (stagger: 0.15).

Efeito Holográfico Fluido: Utilizamos o gsap.quickTo() para calcular a posição do mouse em relação ao centro do card, criando a rotação 3D (rotationX e rotationY) sem gargalos de performance.
